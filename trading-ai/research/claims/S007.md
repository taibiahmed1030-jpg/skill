# S007 — Pairs Trading: Performance of a Relative Value Arbitrage Rule (Gatev, Goetzmann, Rouwenhorst)

**Accès réel : INTÉGRAL — mais version de 1999, pas celle de 2006.** Texte
lu : NBER Working Paper 7032 (35 pages, `https://www.nber.org/system/files/working_papers/w7032/w7032.pdf`),
données CRSP **1962-1997**. Le miroir Wharton (version publiée Review of
Financial Studies 2006, données 1962-2002) n'a pas répondu (timeout).

**Correction du registre** : `SOURCE_REGISTRY.md` décrivait S007 comme
"NBER WP 7032, 2006, 1962-2002, ~1,4 %/mois". C'était un amalgame de
deux versions issu d'un résumé de recherche web. **Les chiffres ci-dessous
sont ceux de la version 1999 effectivement lue** ; ceux de la version
2006 ne sont pas utilisés tant qu'elle n'a pas été lue.

**Incohérence interne relevée dans le papier** : p. 19, l'auteur écrit
que le rendement passe "de 5,98 à 3,99 pour cent **par mois**" alors que
partout ailleurs (Table I, p. 10) ces chiffres sont des rendements
**semestriels**. Lu comme une coquille ; les chiffres semestriels sont
retenus.
